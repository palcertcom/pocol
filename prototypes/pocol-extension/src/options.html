    PoCol Mainnet activation

    Enter the exact schedule approved by the network operator. Use [[1,"0"],[2,"ACTIVATION_HEIGHT"]] for the full 64-bit range, or [[1,"0"]] to keep version 1. Heights must be quoted decimal strings. This setting preserves the chain, genesis and wallet address; it does not upgrade nodes. The gateway cannot change it.

    Network profiles

    Paste the profile.json generated by devnet.py init (containing genesisPre, genesisHash, chainId, endpoint and trustLevel).

    For an approved maximum-range upgrade, include "forkSchedule":[[1,"0"],[2,"ACTIVATION_HEIGHT"]] using the exact activation height from your network operator. Omitting it keeps version 1. The endpoint cannot enable an upgrade for you.

      Local wallet

      For local networks only. The seed is password-encrypted (PBKDF2 600000 + AES-GCM), keys are derived per network, and the wallet locks after 15 minutes.
