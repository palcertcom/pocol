FROM YOUR FIRST IDEA TO A PUBLISHED PAGE

Four steps. Your own space.

  1. 01

    Install the extension

    Download and extract the ZIP. Open chrome://extensions, enable Developer mode and select Load unpacked. Choose the extracted folder containing manifest.json.

  2. 02

    Build your page

    Open Studio and create a project. Choose a template or import your files, add your content, and preview your page on desktop and mobile.

  3. 03

    Review & publish

    Choose Publish to PoCol. In the extension, create or unlock your wallet, review the files and fee cap, then approve and select Confirm & publish.

  4. 04

    Open & share

    Keep the extension tab open until publishing completes. Open your website and share its PoCol address with other extension users.

Already have a PoCol Windows wallet?

The download includes tools/Export-Studio-Wallet.ps1. Run it locally to create an encrypted JSON export with a password of at least 10 characters. Import that file only in the extension confirmation tab and enter the export password there.

Keep building on the same address

Save your project and export a backup from Studio. For later updates, open that project and publish with a wallet authorized for the existing website.

Available on PoCol Mainnet. The extension verifies file hashes and trusts the configured remote node for chain execution. Publishing fees are shown in PCOL for approval before signing.

YOUR FIRST CONTRACT, STEP BY STEP

From source to something you can use.

  1. 01

    Write & compile

    Open the Counter starter in PoCol IDE. Edit Counter.sol, then select Compile. Resolve any errors and select the compiled contract.

  2. 02

    Test locally

    Keep Local sandbox selected. In Deploy, set the initial value to 10 and deploy. In Interact, read count, call increment, then read count again: 11.

  3. 03

    Publish to PoCol

    Install the Chrome extension, select PoCol Mainnet and open Deploy. Enter the constructor inputs and select Continue in PoCol wallet. In the extension, unlock your wallet, review the deployment and PCOL fee cap, then confirm.

  4. 04

    Interact & follow

    Wait for the transaction receipt, then open Interact to read values or call functions. State changes require a new wallet approval. Follow the transaction in Explorer and export your project backup.

Installing or updating the extension

For a new installation, extract the ZIP, open chrome://extensions, enable Developer mode and select Load unpacked. Choose the folder containing manifest.json. For an existing installation, replace the files in the same extension folder and select Reload, then refresh the IDE. Keep the existing extension installation to retain its wallet storage.

Use your Windows or Linux wallet

The extension includes tools/Export-Studio-Wallet.ps1 for Windows and tools/export-studio-wallet.py for Linux. Follow the included instructions to create an encrypted wallet export on your device. Import and unlock it only in the extension wallet tab. The IDE never asks for your private key or wallet password.

Where are my projects and sandbox contracts saved?

Projects are saved in this browser on this site. Export a ZIP to keep a copy outside the browser or move to another device. The local sandbox is temporary: resetting it or reloading the page clears its deployed contracts and simulated balances.

Is the local sandbox the PoCol network?

The sandbox runs Cancun EVM execution locally. It does not publish to PoCol or reproduce PoCol consensus and all network-specific limits. A PoCol Mainnet deployment is a separate transaction and needs an account with PCOL for fees.

PoCol IDE is an experimental development tool. The Mainnet connection checks network identity and relies on the configured remote node. Test your contracts before deploying; starter contracts are learning examples.
