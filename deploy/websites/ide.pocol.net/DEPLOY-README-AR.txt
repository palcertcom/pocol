PoCol IDE — دليل النشر على ide.pocol.net
إصدار المشروع: 0.1.0

1. تجهيز النسخة

تحتاج بيئة البناء إلى Node.js 22.12 أو أحدث وnpm. من مجلد المشروع شغّل:

npm ci
npm test
npm run build

ينشئ الأمر الأخير مجلد dist ويضع نسخة مترجم Solidity المثبتة مع عامل الترجمة داخله. الموقع النهائي ملفات ثابتة؛ لا يحتاج تشغيل Node.js أو خادم تطبيق على cPanel.

للتطوير محلياً بعد البناء الأول:
npm run dev

2. إعداد النطاق ورفع الملفات

أنشئ ide.pocol.net من إعدادات Domains في cPanel، وحدد له مجلد ملفات مستقلاً. مثلاً يمكن أن يكون المجلد public_html/ide حسب إعداد الاستضافة. فعّل شهادة HTTPS للنطاق.

ارفع محتويات مجلد dist إلى جذر الموقع المحدد، وليس مجلد dist نفسه. يجب أن يظهر index.html مباشرة في جذر ide.pocol.net. ارفع جميع المجلدات والملفات معاً، خصوصاً:

- index.html
- assets/ بالكامل، بما فيه ملفات JavaScript وCSS وعمال المتصفح والصور.
- compiler/worker.js
- compiler/soljson.js
- downloads/PoCol-Studio-IDE-Viewer-0.4.1.zip
- licenses/ وTHIRD-PARTY-NOTICES.txt
- أي ملفات إعداد للاستضافة مرفقة بالنسخة، بما فيها الملفات المخفية إن وجدت.

لا ترفع index.html وحده. فقدان ملفات CSS يجعل الصفحة بلا تصميم، وفقدان JavaScript أو عمال المتصفح يمنع المحرر والترجمة والمحاكاة من العمل. هذه النسخة معدة لجذر النطاق وليست لمجلد فرعي.

عند استبدال نسخة منشورة، احتفظ بنسخة احتياطية من ملفات الموقع السابق. ارفع الملفات الجديدة كاملة ثم حدّث الصفحة الرئيسية. إذا كانت هناك طبقة CDN، حدّث كاش HTML بعد الرفع، واترك الأصول المطابقة متاحة أثناء الانتقال.

3. التحقق بعد الرفع

افتح https://ide.pocol.net في متصفح حديث، ثم تحقق من ظهور المحرر والتصميم. يجب أن يعيد المساران التاليان ملفات JavaScript سليمة، وليس صفحة HTML أو خطأ 404:

https://ide.pocol.net/compiler/worker.js
https://ide.pocol.net/compiler/soljson.js

يجب أن يسمح إعداد Content Security Policy، إذا كان مفعلاً في الاستضافة، بتشغيل عمال المتصفح المحليين وWebAssembly. حافظ على نوع المحتوى الصحيح لملفات JavaScript وCSS. لا تضع إعادة توجيه عامة تحول طلبات الملفات الموجودة إلى index.html.

اختبر مشروع Counter:

- اضغط Compile.
- اختر Local sandbox.
- انشر العقد محلياً بقيمة ابتدائية 41.
- اقرأ القيمة، نفّذ increment، ثم اقرأها مرة أخرى؛ يجب أن تصبح 42.
- صدّر المشروع ZIP، ثم افتحه في مشروع جديد للتحقق من النسخ الاحتياطي.

هذا المسار اختُبر فعلياً في واجهة المتصفح، باستخدام مترجم Solidity 0.8.38 ومحرك EVM حقيقي بإعداد Cancun. المحاكاة المحلية تستخدم Chain ID 31337 وأرصدة تجريبية بلا PCOL حقيقي. إعادة تحميل الصفحة أو إعادة ضبط المحاكاة تمحو العقود والأرصدة المحلية فقط. لا تحاكي هذه البيئة إجماع PoCol أو عقوده النظامية أو جميع حدود الشبكة.

4. الاتصال بمحفظة PoCol والنشر على الشبكة

المسار الأساسي هو إضافة PoCol للإصدار 0.4.0 المرفقة مع هذه النسخة. اسم الحزمة PoCol-Studio-IDE-Viewer-0.4.1.zip، ورابطها بعد نشر الموقع:
https://ide.pocol.net/downloads/PoCol-Studio-IDE-Viewer-0.4.1.zip

يمكن استخدام محفظة خارجية متوافقة مع EIP-1193 اختيارياً.

للتثبيت لأول مرة، فك حزمة الإضافة ثم افتح chrome://extensions، فعّل Developer mode، واختر Load unpacked وحدد المجلد الذي يحتوي manifest.json.

لتحديث إضافة غير مضغوطة موجودة بالفعل، احتفظ بنسخة محفظة مشفرة وكلمة مرورها. استبدل ملفات الإضافة داخل مجلدها الحالي نفسه، ثم اضغط Reload من chrome://extensions. لا تحذف الإضافة ثم تعيد تثبيتها كخطوة تحديث؛ الحفاظ على التثبيت نفسه مهم لبيانات المحفظة المحلية. ملفات تطبيقات Windows وLinux الأصلية لم تتغير ضمن إصدار الويب والإضافة هذا.

استخدم النسخة المطابقة لهذا الإصدار من IDE. تدعم الإضافة أصلي الموقع التاليين:
https://ide.pocol.net
https://pocol-ide.mystic-gecko-9511.chatgpt.site

النطاقات الأخرى تحتاج إضافتها إلى إعداد الإضافة قبل الاتصال منها.

افتح المحفظة داخل الإضافة، ثم اتصل بها من IDE. عند استخدام محفظة Windows حالية، يتم استيراد التصدير المشفر في واجهة الإضافة فقط. مستورد المشاريع في الموقع مخصص لملفات العقود والمشاريع، وليس لملفات المحفظة. لا تدخل عبارة الاسترداد أو المفتاح الخاص أو كلمة مرور المحفظة في صفحة الويب؛ فك القفل والتوقيع يتمان داخل الإضافة.

اختر PoCol Mainnet وتحقق من الشبكة، ثم ترجم آخر نسخة من العقد. أدخل معاملات المنشئ وراجع قيمة التحويل والحد الأقصى للرسوم، ثم وافق من الإضافة. رمز العملة PCOL، بينما اسم الشبكة والمنتج PoCol.

إعدادات الشبكة:
Chain ID: 1599846715
Chain ID (hex): 0x5f5bb93b
RPC: https://gateway.pocol.net/studio/rpc
Explorer: https://explorer.pocol.net
Currency: PCOL — 18 decimals
Genesis: 0xbe137bfdb4fdf332f2e1500ee1a67e0b22ce6bdf57efa46fb4ea7b0debe509ca

تم التحقق من Chain ID وGenesis للبوابة الحية من المتصفح عند الكتلة 10922. لم يُتحقق حتى الآن من مسار العقود في الإضافة الجديدة باستخدام مفتاح توقيع حقيقي، ولا من معاملة نشر فعلية على الشبكة العامة من البداية إلى النهاية بمحفظة ممولة. نجاح اختبار المحاكاة المحلية لا يعني أن هذا الاختبار على الشبكة العامة قد تم. يظل التحقق من الاتصال والموافقة والتوقيع وظهور إيصال النشر على الشبكة خطوة إصدار مطلوبة. الاتصال الحالي يعتمد على عقدة RPC بعيدة موثوقة.

5. الملفات والمشاريع والتراخيص

واجهة الموقع والمحتوى الافتراضي باللغة الإنجليزية. تُحفظ مشاريع المستخدم محلياً في المتصفح؛ لا تنتقل تلقائياً بين الأجهزة أو النطاقات أو ملفات تعريف المتصفح. صدّر ZIP قبل مسح بيانات الموقع أو الانتقال من رابط المعاينة إلى ide.pocol.net. تغيير ملفات الموقع منفصل عن تغيير محفظة الإضافة.

لا يجلب المترجم استيرادات من الإنترنت. أضف ملفات الاعتماد Solidity إلى المشروع نفسه. الترجمة والتنفيذ المحلي لهما مهلة 60 ثانية، ويجب إعادة نشر العقود المحلية إذا انتهى عامل المحاكاة أو أُعيد ضبطه.

احتفظ بملف THIRD-PARTY-NOTICES.txt ومجلد licenses/ مع النسخة المنشورة. يتضمنان النصوص الأصلية للتراخيص ومراجع المصدر المطابق للإصدارات. حزمة solc تحتوي غلاف JavaScript بترخيص MIT، بينما مترجم Solidity الأساسي بترخيص GPLv3. تتضمن EthereumJS مكونات MIT وأخرى MPL-2.0. تفاصيل الإصدارات والمصادر في ملف الإشعارات.

تصدير محفظة لينكس الحالية: داخل حزمة الإضافة tools/export-studio-wallet.py. يحتاج Python 3 وحزمة python3-cryptography، ويُشغَّل بحساب مالك ملف المحفظة مع --key-path و--output. اقرأ README-AR.md داخل حزمة الإضافة. التصدير مشفّر ولا يغيّر المحفظة الأصلية.
