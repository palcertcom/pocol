# نسخ المصدر المراجعة والتحقق المسبق لدفعة PR29

وصلت محاولة المالك الثانية إلى التحقق من instances ثم توقفت عند
`Another open ref has a different location`. كان التحقق يشترط موقعًا واحدًا
وSHA256 واحدًا لكل الفروع، رغم أن المراجعة التاريخية والمراجعة الحالية
تحتويان على نسختين مستقلتين من `earnin_halt_proof.rs` بأسطر مختلفة.
لا تثبت رسالة التوقف وحدها أي ref كان مختلفًا أو عدد الحالات التي سبقتها؛
سجل المالك هو المرجع لحالة محاولته الفعلية.

النسخة القديمة عند main `46d688b` روجعت بالفعل ضمن خطة الـ197 المثبتة بـSHA256.
أُعيد استخراج ملفها من Git وتحقق hash الكامل:

```text
91ff0afc5975ddcda0b6976f39b71986f8d297e15225f6f7e0ab10f1f447468f
```

تشمل مراجعتها سبعة مواضع لعدادات EVM العامة: التنبيهات التاريخية
47 و48 و49 و52 و57 و58 و59. يقابل السطر القديم 51 السطر الحالي 39، و53 يقابل
41، و62 يقابل 50، و70 يقابل 58. تؤكد [بيانات النسخة القديمة](evidence/pr29-reviewed-older-source.json)
المصدر الكامل والـcommit والـhash، دون إعادة إدخاله ككود تطبيق.

بقي اكتشاف الأهداف محصورًا بالمواقع الـ11 في PR29. وبقيت نسخ PR29 نفسها
مطالبة بموقعها الحالي وhash المراجعة الحالية حرفيًا. أما أي ref آخر فيجب أن
يطابق **موقعًا وhash للملف الكامل سبق أن روجعا معًا**، للقاعدة والمسار وقرار
False positive أنفسهم. لا يكفي تشابه نص السطر أو مقدار انتقال الأسطر أو hash
معروف مع موقع غير مراجع. لا تتغير خطة الـ197 ولا تُغلق دفعتها بهذه الأداة؛
تُستعمل مراجعتها كدليل لنسخ معروفة فقط.

تتحقق الأداة من الدفعة قبل أول PATCH، ثم تعيد قراءة instances وثبات main وHEAD
قبل كل PATCH. إذا ظهر مصدر أو موضع غير مراجع، يبقى مانعًا للإغلاق. يسجل JSON
المرحلة وبيانات `blocked_instance`، ومنها رقم التنبيه والـref والـcommit والموقع
والـhash عند توفره. يوضح `decisions` الحالات التي عولجت فعلًا، و`preflight`
القراءات السابقة للكتابة.

أعادت الاختبارات إنتاج فشل النسخة القديمة المراجعة قبل التعديل: اختباران يفشلان
عند مقارنة السطر القديم 51 بالحالي 39. بعد التعديل مرت **38/38** تجربة محاكاة،
منها رفض تعديل بايت في المصدر القديم، ورفض موقع قديم غير مراجع، وفرض مراجعة
PR29 الحالية على مرجعه، ومنع كل الكتابات إذا أخفقت حالة لاحقة في preflight،
وإعادة التحقق قبل كل كتابة. [سجل قبل](evidence/codeql-cross-ref-before.log)
و[سجل بعد](evidence/codeql-owner-helpers-38-tests.log).
