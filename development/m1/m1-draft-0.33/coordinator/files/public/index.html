    History: past and current

    Historical cards are imported from workspace files without running any agent. Current cards contain receipts for author tasks run by this broker and reviews actually recorded by the host coordinator through the reviewer interface. Cards follow recorded timestamps; an absent timestamp shows “Unavailable” and retains its position among neighboring cards. Only permitted text is displayed: response text, tool calls and abbreviated results, and the final result. Internal model reasoning and secret values are not displayed.
