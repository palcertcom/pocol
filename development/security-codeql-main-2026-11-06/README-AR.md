أو مفاتيح أو رموز دخول. إذا تغيّر `main` أثناء الجمع، يسجل ذلك ويخرج بالرمز 2؛

## حزمة فحص ART/JNI على الهاتف

يبني workflow **Security owner evidence tools and Android probe** برنامج DEX
صغيرًا، ويضم المكتبتين ARM64 الفعليتين من حزمة Android الناجحة:

- مصدر المكتبات: `03190bed86aacc8e9fdaa895c5be349031bcceb5`.
- التشغيل: `42208222279`؛ artifact: `13497272552`، مع فحص هويته ونجاحه.
- بصمة التوافق: `116dda56f203c46bb31e84ab3022254160db2ee486e21f209ec1de2df81a9973`.

يتحقق البناء من مخزون ملفات Rust ومن تطابق شجرة المنتج والبناء مع ذلك المصدر،
ومن ELF ARM64 ومحاذاة 16 KiB. أي تقدم لاحق في المصدر يستلزم حزمة جديدة ومراجعة
هوية البناء، بدل إعادة استخدام مكتبات قديمة. قد تنتهي صلاحية artifacts؛ فشل
تنزيلها أو غيابها لا يعد نجاحًا. الحزمة الجديدة اسمها
`pocol-android-art-probe-<commit>`، وتشمل المكتبات وDEX وبصماتها وبيانات منشئها.

يتطلب التشغيل هاتف ARM64 بنظام Android 8 أو أحدث، وUSB debugging بإذن المالك،
و`adb` من Android Platform Tools. افتح اتصال USB وافق على طلب الهاتف بالطريقة
المعتادة؛ الأداة لا تغير هذه الإعدادات. لا يلزم JDK أو SDK كامل على جهاز المالك.

نزّل حزمة workflow الناجح إلى مجلد جديد، ثم شغّل:

```powershell
gh run download <RUN_ID> --repo palcertcom/pocol --name pocol-android-art-probe-<COMMIT> --dir android-art-probe
python development/security-codeql-main-2026-11-06/run_device_probe.py --bundle android-art-probe --out android-art-device-2026-11-06.json
```

استبدل `<RUN_ID>` و`<COMMIT>` بالقيم الفعلية للتشغيل الناجح؛ يمكن إعطاء مسار
`adb.exe` باستخدام `--adb`، واختيار الجهاز باستخدام `--serial` عند تعدد الأجهزة.
لا تشغل الأمر الثاني إلا على هاتف تملكه أو مأذون لك بفحصه. الإجراء يرفض
معرّفات المحاكي واتصال ADB الشبكي، لكن غياب أعلام المحاكي لا يثبت وحده أن الجهاز
حقيقي؛ تأكيد المالك يبقى جزءًا من دليل الفحص.

تتحقق الأداة من بصمات الحزمة والنقل، ثم تشغّل `app_process64` مع فحص JNI في
مجلد عشوائي تحت `/data/local/tmp`. لا تثبّت APK أو توقعه، ولا تستدعي إنشاء
الهوية أو استيراد الشبكة أو ترقيتها أو تشغيل العقدة. الملفات الوحيدة المنشأة
للفحص إعدادات اختبار غير صالحة؛ تُحذف مع المجلد المؤقت عند النهاية إن بقي
الاتصال بالجهاز متاحًا. لا تُقرأ بيانات التطبيق أو المحافظ ولا يُجمع logcat.

المجموعات التسع تفحص حالة المكتبة قبل/بعد، ودخول مسارات Unicode وخروجها،
ورفض null وNUL وsurrogates غير المزدوجة، وحدود UTF-8 بالبايت، ورفض أوامر غير
صالحة دون وضعها في الطابور. لا تعادل هذه النتيجة فحص واجهة التطبيق أو دورة
الخلفية أو تحديث APK بتوقيع الإصدار أو التحقق من شبكة متعددة الأجهزة.
