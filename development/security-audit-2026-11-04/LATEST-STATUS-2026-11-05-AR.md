## CodeQL: ما ثبت وما بقي

دمج المالك [PR24](https://github.com/palcertcom/pocol/pull/24) في main. أظهر [تشغيل CodeQL بعد الدمج](https://github.com/palcertcom/pocol/actions/runs/42009117424) نجاح وظائف اللغات الثماني، وأظهرت صفحة المالك أن **#7 Fixed عبر PR24**. هذا إصلاح TLS فعلي، مختلف عن تصنيف إنذار غير منطبق. لم يُكرر إصلاح TLS في هذه الدفعة.

يصل التكامل إلى GitHub Actions وبيانات المستودع، لكن Code scanning API يرد `403 Resource not accessible by integration`. لم يُنزّل SARIF الأصلي الكامل لـCodeQL أو جميع المسارات الفردية. استُخدمت صادرات المالك ولقطات التفاصيل، مع قراءة المصدر المثبت ومراجعة أصل البيانات. [الفرز المفصل وحدوده](CODEQL-TRIAGE-2026-11-05-AR.md).

- تصدير الملفات يضم 693 مسارًا فريدًا، جميعها موسومة بنجاح الاستخراج. CSV لا يضم SHA أو وقت كل analysis؛ ليس شهادة تغطية دلالية كاملة. بقي 29 مسارًا من الفئات الممثلة غير مدرج، وبعضها حزم JavaScript تعمل في المنتج وملف schema.ts للـCP. كما لا يمثّل التصدير PHP وSolidity وShell وPowerShell وBatch. لا تُحسب هذه الفروق آليًا كثغرات أو إخفاقات استخراج.
- تصدير الاستعلامات يخص Rust فقط: 26 صفًا، منها 17 قاعدة أمنية و9 ملخصات/قياسات. حزمة المصدر المثبتة `codeql/rust-queries 0.1.46+1be292a1e54696ca543b4ad0f9b4537b9687caa7`؛ العددان 193 للتشفير الثابت و21 للتسجيل أعداد نتائج الفحص، وليسا عدد ثغرات أو عدد Open الحالي.
- آخر لقطة مالك: 212 Open إجمالًا، و14 Open و7 Closed لقاعدة `rust/cleartext-logging`. راجعت المجموعة التالية #208–#214 ووجدتها غير منطبقة في سياقات EVM المصطنعة المغلقة؛ لم يغيّر المساعد حالتها. السبعة الأخرى من القائمة لم تُراجع مواضعها بعد. لم يُعطّل استعلام أو يُستثن ملف أو يُحذف assert لإخفاء نتيجة.

## تحقق Windows وتحذيرا C# وGo

نجح [تشغيل Windows Wallet UI 42025519955](https://github.com/palcertcom/pocol/actions/runs/42025519955) على `fd29d33`: خطوة بناء WPF واختبارات regression قبل/بعد ناجحة بحسب بيانات التشغيل. ملفات المدخلات الثمانية مطابقة بايتًا لـmain المرجعي. لم يُنزّل artifact الخام لأن مضيف إعادة التوجيه `productionresultssa6.blob.core.windows.net` غير مسموح؛ لم تُتحقق بصمته محليًا أو تُراجع سجلاته الخام. نجاح التشغيل لا يعني مراجعة كل تدفقات Windows.

**يبقى تحذير جودة C# مفتوحًا**: التحليل بوضع build-mode none، مع 59% من calls مع target معروف و71% من expressions مع type معروف مقابل عتبة 85%. لم يُعد CodeQL بتحليل بناء WPF، ولم تُثبت زيادة هذه المقاييس.

**يبقى تحذير Go مفتوحًا**: الملف الوحيد مرجع اختبار مقارن لـGeth، وتعذر حل تسع حزم. نُزّل Go 1.27.3 الرسمي وتحققت بصمته، لكن `go mod tidy` توقف عند إعادة توجيه إلى `storage.googleapis.com` المحجوب؛ لم يُنفّذ بناء Go أو اختباره، ولم يُغيّر إصدار Geth أو إعداد CodeQL. [النتيجة المسجلة](evidence/codeql-review-2026-11-05/quality-result.json).

## العمل المتبقي

1. مراجعة إصلاحات المسودة ونتيجة CI على رأس التسليم نفسه قبل اتخاذ قرار الدمج.
2. فرز بقية تنبيهات CodeQL بحسب أصل البيانات ومسارها، ومراجعة الإنذارات الحرجة؛ لا يُعمم حكم الاختبارات المصطنعة على مفاتيح حقيقية أو الشيفرة المنتجة.
3. معالجة سياق بناء C# وGo ثم قياس جودة CodeQL مجددًا، ومراجعة الحزم واللغات والمسارات التي لا يثبت التصدير تغطيتها.
4. تقييم خطر توقيت crypto-bigint ومعالجة اعتماداته المتوافقة، وtmp وديون الصيانة، مع أدلة وصول وتوافق بدل suppression شامل.
5. اختبار الإضافة في متصفح تسمح سياسته بتحميلها، وAndroid ART/جهاز فعلي، والمسارات الكبيرة وقياسات أسوأ الحالات. يبقى أيضًا الفصل بين نجاح الفحوص والادعاء بسلامة كل المنتج.
